# 專案規則

## 技術限制
- 純 HTML／CSS／JavaScript，不使用 Node.js、Vite、任何前端框架或外部 API
- 所有相依資源（字型、圖示等）若需使用，需以本地檔案方式放入專案，不透過 CDN 或外部請求

## 目錄結構
- 網站所有程式檔案（HTML、CSS、JS、圖片等）統一放在 `docs/` 資料夾下
- Kiro 設定檔放在 `.kiro/` 資料夾下

## 資料處理
- 所有資料使用模擬資料（mock data），以 JavaScript 物件／陣列直接定義於程式中
- 不呼叫任何外部 API 或後端服務

## 語言
- 介面文字、說明、標籤一律使用繁體中文

## 響應式設計
- 所有頁面須支援響應式設計，相容桌機、平板、手機等不同螢幕尺寸

## 發布
- 使用 GitHub Pages 從 `main` 分支的 `docs/` 資料夾發布網站
